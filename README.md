# ArtCraft Studio

An intentional crafting engine and unified creative hub for artists, designers, and filmmakers built in pure Rust, powered by the **Martensite** GPU-accelerated retained-mode GUI engine.

![ArtCraft Studio on Martensite](brag/demo.gif)

## Architecture

- **`crates/ui-martensite`**: Sovereign retained-mode creative hub interface, project manager, and cross-application asset browser.
- **`crates/engine`**: Core procedural generation graph, GPU 3D rendering pipeline, and multi-app IPC synchronization.

## Legal & Compliance Notice

ArtCraft is an independent open-source creative platform. All project management workflows, asset pipelines, and interface architectures are developed clean-room.
